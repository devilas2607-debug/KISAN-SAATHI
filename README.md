# 🌾 ABOUT THE PROJECT

**Kisan Saathi** is a full-stack agricultural procurement and mandi logistics management platform designed to solve one of the major operational challenges faced by farmers during peak harvest and procurement seasons: **long, unpredictable, and inefficient physical queues at procurement centres**.

The platform digitally connects:

```text
👨‍🌾 FARMERS
      │
      ▼
📱 KISAN SAATHI
      │
      ├──────────────► 🏪 MANDI OPERATORS
      │
      └──────────────► 📊 ADMINISTRATORS
